# Hóa học 10 — Chuyên đề 2, Bài 6

Bài trình chiếu tương tác về điểm chớp cháy, hóa học của phản ứng cháy và phòng chống cháy.

## Cách xem
- Mở `index.html` trên GitHub hoặc bật GitHub Pages trong **Settings → Pages** để xuất bản thành website.
- Dùng nút **Trước/Tiếp theo** hoặc phím mũi tên trái/phải để chuyển slide.
- Cuối bài có 5 câu hỏi trắc nghiệm, chấm điểm và giải thích đáp án tự động.

## Tài liệu
SGK Chuyên đề học tập Hóa học 10, Bài 6 — liên kết tài liệu được đặt trong slide cuối.
